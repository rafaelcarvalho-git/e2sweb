## 🚀 Sobre o Projeto

Este projeto consiste em um website institucional desenvolvido sob medida para a **E2S Corretora de Seguros LTDA-ME**. O objetivo principal foi criar uma plataforma online robusta para consolidar a presença digital da empresa, permitindo a prospecção de clientes e a divulgação transparente de seus serviços e seguradoras parceiras.

A construção do sistema serviu como prática essencial para dominar a estruturação de layouts semânticos multi-páginas, integração de frameworks utilitários de estilização e deploy automatizado em infraestrutura Cloud.

---

## ✨ Funcionalidades Principais

- 🗂️ **Arquitetura Multi-páginas (MPA):** Navegação fluida dividida estruturalmente entre as seções Principal (`index.html`), Quem Somos (`quemsomos.html`), Serviços (`servicos.html`) e Contato (`contato.html`).
- 🧭 **Menu de Navegação Dinâmico:** Navbar responsiva controlada via script (`js/navbar.js`) que se adapta perfeitamente a dispositivos móveis e desktops.
- 🤝 **Vitrine de Parceiros:** Carrossel interativo exibindo a carteira de seguradoras integradas (Porto Seguro, Azul, Bradesco, Tokio Marine, Allianz, Mapfre, HDI, entre outras).
- 📍 **Central de Atendimento:** Página de contato estruturada para captação de leads com canais de localização, e-mail e links diretos para suporte.
- 🎨 **Estilização Modular:** Layout visual moderno e organizado com arquivos CSS escopados por contexto de página (`carousel.css`, `navbar.css`, `footer.css`, etc).

---

## 🛠️ Tech Stack

- **Estruturação:** HTML5 Semântico
- **Estilização e Responsividade:** CSS3 + Bootstrap Framework
- **Interatividade:** JavaScript Vanilla (ES6)
- **Hospedagem e Infraestrutura:** Firebase Hosting
